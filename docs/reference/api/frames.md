# `dpmxbrl.frames`

Columnar reading of large xBRL-CSV packages into polars frames. Needs the
`frames` extra (`pip install "dpm-xbrl[frames]"`). Everything on this page
is in `dpmxbrl.frames.__all__`.

See [read large reports as frames](../../guides/large-reports.md).
